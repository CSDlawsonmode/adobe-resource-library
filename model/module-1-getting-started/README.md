# Module 1 model: Getting Started ("Liftoff")

Version 2: the same retro-future flight-manual look as the Photoshop module, kept simple (KISS) and meant to stay open while a new teacher sets up.  Adapted from Media Tech Fundamentals **Unit 1 – Digital Foundations**.

## Files

| Path | What it is |
|---|---|
| `pages/*.html` | **The source.** Five Canvas pages, inline styles only. |
| `preview.html` | All five pages on one page with the art embedded.  Generated: run `python model/build_preview.py`. |
| `../theme/banner-getting-started.svg` | The "LIFTOFF: The First Two Days" banner, plus the shared starfield and console strip.  Generated: run `python model/make_theme_assets.py`. |

## Pages

1. **Start Here** (Mission Briefing): the First Law of Day One ("every student signed in before the bell"), a navigation table, and the two-day mission
2. **Creative Cloud in 5 Minutes** (Instrument Panel): what students sign into, a before-day-one checklist, which app does what, where files go, and file types
3. **The First Two Days** (Flight Plan): a pre-flight checklist, Day 1 and Day 2 minute by minute, and adapting the plan
4. **Lesson Kits** (Mission Files): Set Up Your Workspace and The Professional Email, with copy-to-students boxes and the Getting To Know You questions
5. **Help! I Can't Get In** (Distress Signals): sign-in problems with fixes, four file-naming rules, and multilingual learners

There are **8 Mission Checks**, each a scenario question with a hidden answer that explains why the wrong answers are wrong.

## Sharing project files (added 2026-11-16)

Students turn in the **project file itself, shared with the teacher**, not an exported picture of it, so the teacher can open it and see the layers.  This also teaches sharing.
- **Lesson 1** now ends with sharing the class folder with the teacher, then sharing a file with a partner and opening theirs.  Every project saved there afterward is already turned in.
- **Photoshop module** updated to match: share the .psd to turn in, export a copy to show off, and share with a partner before feedback day.
